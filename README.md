# Digger — релизы игры

Этот репозиторий хранит готовые сборки Digger, описание изменений и сведения
об их происхождении. Unity-проект находится отдельно в
[DmytroMaliarenko/Digger](https://github.com/DmytroMaliarenko/Digger).

## Скачать

Откройте [Releases](https://github.com/DmytroMaliarenko/Digger-releases/releases)
и скачайте `Digger-Windows.zip` из нужного выпуска.
Распакуйте архив в отдельную папку и запустите `Digger.exe`.

Архивы **Source code**, автоматически создаваемые GitHub, не являются игрой.
Репозиторий публичный: просмотр и скачивание не требуют аккаунта GitHub.
Игра пока находится на стадии прототипа. Начиная с v0.2.0 выпуски публикуются
как **Latest** для совместимости с адресом автообновления.

Постоянный адрес манифеста:
[version.json](https://github.com/DmytroMaliarenko/Digger-releases/releases/latest/download/version.json).
Поля `version` и `windows` соответствуют формату обновления Co-op.
Поле `windows` указывает на ZIP конкретной версии; `Digger.exe` находится в корне архива.
Это серверная подготовка: клиент автообновления внутри Digger пока не реализован.

## Состав выпуска

- Windows ZIP: исполняемый файл, Unity-библиотеки, данные игры и инструкция.
- `version.json`: версия, адрес Windows ZIP, платформа, точный commit исходников, SHA-256 ZIP,
  версия Unity и результаты автоматической проверки.
- `SHA256SUMS.txt`: контрольные суммы ZIP и манифеста.
- Описание релиза: изменения, управление, известные ограничения и ссылка на исходники.

Исходники остаются приватными и имеют соответствующий тег `v<версия>` в репозитории Digger.
В этом репозитории тег указывает на служебные файлы релиза; точный игровой
commit всегда указан в `version.json`. Опубликованные версии и их файлы
не заменяются: исправления выходят под новым номером.

## Подготовка следующих релизов

Сценарии находятся в исходном проекте: `Tools/Release` и
`Documentation/Releases.md`. Сборка и smoke-проверка выполняются локально
через Unity Pipeline. Публикация идёт в GitHub Releases; Unity-лицензия или
личный токен не загружаются в этот репозиторий.

Для сообщения об ошибке создайте Issue и укажите версию, seed (F3), шаги
воспроизведения и, если возможно, кадр проблемы.
